# US Extensions — RainPath POC

## Epic D — Déploiement (Docker)

- **US-D01** : En tant que développeur, je veux un `Dockerfile` pour le backend NestJS afin de le containeriser
- **US-D02** : En tant que développeur, je veux un `Dockerfile` pour le frontend React (build statique servi via nginx) afin de le containeriser
- **US-D03** : En tant que développeur, je veux un `docker-compose.yml` pour lancer l'ensemble de la stack (frontend + backend) avec une seule commande

## Epic V — Refonte visuelle

- **US-V01** : En tant qu'utilisateur, je veux un mode sombre (dark mode) sur l'ensemble de l'application
- **US-V02** : En tant que chef de labo, je veux voir mes workflows organisés par onglets selon leur statut (Brouillon / Validé / Annulé) sur la page de liste
- **US-V03** : En tant que chef de labo, je veux que chaque node affiche un logo/icône représentatif de son canal ou de son type (Email, SMS, WhatsApp, Courrier, Délai, Condition...)
